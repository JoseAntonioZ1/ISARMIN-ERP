# ISARMIN ERP

ERP profesional para la gestión integral de ISARMIN PERÚ S.A.C.

## Estado

🚧 En fase de análisis y arquitectura.

## Objetivo

Desarrollar un sistema ERP moderno para gestionar:

- Inventario
- Ventas
- Compras
- Taller de reparaciones
- Servicios de campo
- Caja
- Reportes
- Usuarios y permisos
- Configuración

## Tecnologías (propuestas)

- React + TypeScript
- ASP.NET Core Web API
- PostgreSQL
- Tailwind CSS
