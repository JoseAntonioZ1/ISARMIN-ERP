# Business-Risks.md — Registro de Riesgos de Negocio

## 1. Propósito

Registro de riesgos siguiendo el enfoque de **BABOK v3** (Risk Analysis and Management) — riesgos que amenazan el éxito del proyecto o de la operación del negocio una vez digitalizada, evaluados en **probabilidad** e **impacto**, con una mitigación propuesta. Este documento se enfoca en riesgos de **negocio y de proceso**; los riesgos puramente de implementación técnica se evaluarán con mayor detalle durante la fase de arquitectura, aunque varios de los aquí listados anticipan esa discusión porque nacen de una decisión de negocio (ej. infraestructura on-premise).

## 2. Convención

**Probabilidad / Impacto:** Alta, Media, Baja. **Categoría:** Negocio, Datos, Cumplimiento, Operacional, Proyecto, Tecnológico.

## 4. Priorización sugerida

Para la siguiente etapa de levantamiento con el cliente, se recomienda resolver primero los riesgos marcados con **impacto Alto**, dado que todos ellos condicionan decisiones de modelo de datos o de arquitectura difíciles de revertir una vez iniciado el desarrollo: **RSK-001, RSK-002, RSK-003, RSK-004, RSK-007, RSK-011, RSK-013, RSK-014**.

## 5. Nota

Este registro debe revisarse y actualizarse en cada hito del proyecto (fin de levantamiento, fin de diseño de arquitectura, antes de cada release), conforme a la práctica de gestión continua de riesgos de BABOK.
