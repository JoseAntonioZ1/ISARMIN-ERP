Siempre que trabajes en este proyecto debes seguir estas reglas:

- Nunca elimines funcionalidades sin autorización.
- Nunca cambies la arquitectura sin justificarlo.
- Sigue principios SOLID.
- Sigue Clean Architecture.
- Sigue Clean Code.
- No generes código duplicado.
- No inventes funcionalidades.
- Consulta la documentación antes de implementar.
- Toda funcionalidad debe estar documentada.
- Todo código debe estar comentado cuando sea necesario.
- Prioriza mantenibilidad sobre rapidez.
- Utiliza nombres descriptivos.
- No modifiques la base de datos sin actualizar la documentación.
